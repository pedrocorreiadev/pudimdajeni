# Pudim da Jeni

A responsive website created for **Pudim da Jeni**, a small handmade pudding business based in Rio Branco, Acre, Brazil.

The project focuses on presenting the products in a simple and attractive way while making it easy for customers to place orders directly through WhatsApp.

## Features

- Responsive design for desktop and mobile
- Product and price sections
- Order information
- WhatsApp integration
- Floating WhatsApp button
- Instagram link
- FAQ section
- Smooth animations
- Handmade dessert-inspired visual identity
- SEO-friendly structure

## Technologies

- HTML5
- CSS3
- JavaScript
